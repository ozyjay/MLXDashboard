# MLXDashboard

Native macOS SwiftUI dashboard for owning a local `mlx-lm` server, installing MLX-compatible Hugging Face models, and exposing a token-protected OpenAI-compatible localhost provider for MLXChat.

- [MLX-LM runtime and model planning](docs/notes/mlx-lm-runtime-and-model-planning.md): runtime choice, localhost-only server binding, context budgeting, model-role presets, and 64GB memory guidance.
